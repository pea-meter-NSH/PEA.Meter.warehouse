สรุปตำแหน่งและสภาพปัจจุบันของมิเตอร์ที่ลงทะเบียน

PEA มิเตอร์ สภาพ คำอธิบายพัสดุ พิกัดแอมป์ เลขอ่านล่าสุด สถานะ ผู้ปฏิบัติงาน วันที่อัปเดต ดูประวัติ

📦 ตรวจสอบมิเตอร์คงคลังพร้อมใช้ และเบิกใช้ด่วน

ค้นหามิเตอร์ที่มีอยู่ในสต็อกคลังสะสม (ทั้งคลังใหม่และคลังเก่า) และสั่งทำรายการเบิกใช้ได้ทันที

PEA มิเตอร์ สภาพมิเตอร์ คำอธิบายรหัสพัสดุ แอมป์/อัตราส่วน เลขอ่านล่าสุด วันที่นำเข้าคลัง ผู้รับเรื่อง การจัดการ

📥 นำเข้ามิเตอร์ด้วยไฟล์ Excel (.xlsx / .xls / .csv)

คุณสามารถอัปโหลดไฟล์ Excel เพื่อดึงรายละเอียดทั้งหมดเก็บเข้าคลังสินค้าได้อัตโนมัติ

📌 คำแนะนำคอลัมน์ Excel:
• รหัส PEA (คอลัมน์ B) • แอมป์/อัตราส่วน (คอลัมน์ G) • คำอธิบายรหัส (คอลัมน์ E)
• ตรวจหา สภาพมิเตอร์ (ใหม่/เก่า) จาก แบทช์สต็อค (คอลัมน์ F: N = ใหม่, R = เก่า) และวันที่ถอนคืน (คอลัมน์ N)
