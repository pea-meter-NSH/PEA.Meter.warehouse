สัดส่วนรายการบันทึกมิเตอร์

เปรียบเทียบจำนวนรายการนำเข้า เบิกใช้ และแจ้งชำรุด

ยังไม่มีข้อมูลสำหรับแสดงกราฟ

เมื่อมีการลงบันทึกเบิกใช้ นำเข้า หรือแจ้งชำรุด กราฟจะแสดงผลอัตโนมัติ

สถานะล่าสุดของมิเตอร์แต่ละรหัส

สรุปสถานะล่าสุดตามรหัสมิเตอร์ที่มีการบันทึกในระบบ

PEA มิเตอร์ ประเภท เลขอ่าน หมายเลขผู้ใช้ไฟ สถานะล่าสุด ผู้บันทึก (รหัสผู้ใช้) วันที่ล่าสุด

📦 ตรวจสอบมิเตอร์คงคลังและทำรายการเบิกด่วน

ค้นหามิเตอร์ที่มีอยู่ในคลังปัจจุบัน และคลิกปุ่มเบิกใช้งานเครื่องดังกล่าวได้ทันที

PEA มิเตอร์คงคลัง สภาพมิเตอร์ คำอธิบายรหัสพัสดุ แอมป์/อัตราส่วน เลขอ่านล่าสุด วันที่นำเข้าล่าสุด ผู้รับเรื่องนำเข้า ดำเนินการเบิกใช้

ประวัติการลงบันทึกมิเตอร์ทั้งหมด

ตรวจสอบรายการเบิกใช้ นำเข้า และแจ้งชำรุด พร้อมรูปภาพและหมายเหตุ

วันที่บันทึก ประเภทรายการ สภาพมิเตอร์ PEA มิเตอร์ เลขอ่าน หมายเลขผู้ใช้ไฟ รหัสผู้ใช้ ชื่อผู้บันทึก (เบอร์โทร) หมายเหตุ / อาการชำรุด รูปภาพ การจัดการ (Admin)

📥 นำเข้ามิเตอร์ด้วยไฟล์ Excel (.xlsx / .xls / .csv)

คุณสามารถอัปโหลดไฟล์ Excel ของคุณเพื่อดึงหมายเลข PEA และรายละเอียดทั้งหมดเพื่อจัดเก็บเข้าคลังสะสมได้อัตโนมัติ

📌 ตารางดึงข้อมูลอัตโนมัติ:
• ดึงรหัส PEA (คอลัมน์ B) • แอมป์/อัตราส่วน (คอลัมน์ G) • เลขคำอธิบาย (คอลัมน์ E)
• ตรวจจับ คงคลัง (ใหม่/เก่า) จาก แบทช์สต็อค (คอลัมน์ F: N = ใหม่, R = เก่า) และวันที่ถอนคืน (คอลัมน์ N) ทันที
